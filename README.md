# Sammit Portfolio Template

A clean, responsive, single-page portfolio built with React, Vite, Tailwind CSS v4, Framer Motion and Lucide React.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

1. Edit `src/data/profile.js` with your email, GitHub and LinkedIn URLs.
2. Edit `src/data/projects.js` with your real project details and repository/demo URLs.
3. Add your PDF resume as `public/resume.pdf`.
4. Replace the sample education and skills in `src/data/` or their corresponding components.
5. Search for `TODO: PERSONALIZE` to find sample content that should be reviewed.

## Notes

- This is a clean starter template. It does not include `node_modules`; install dependencies with `npm install`.
- The contact section uses a `mailto:` link. It is not a backend-powered contact form.
- Empty demo URLs are intentionally hidden.
- Do not publish placeholder links or claims. Verify all project descriptions and results first.
